# Резултати от ръчно проучване (Gemini)

Тук отиват суровите резултати, върнати от Gemini (през безплатната уеб квота, не през API), за градовете от
`docs/manual-research/cities.md`, преди да минат през стъпката „структуриране“.

## Именуване на файловете

Един файл на град, кръстен на самия град (кирилица, интервалите заменени с `_`):

```
Асеновград.md
Велико_Търново.md
Горна_Оряховица.md
```

## Съдържание на файла

Пълният отговор на Gemini за трите партиди (basic/vik/ethnos/transport/power,
security/social/health/services/industry, connectivity/culture/risks/environment/history),
събран в един файл, във формата, който самият промпт изисква
(`## КАТЕГОРИЯ: <идентификатор>` + `ИЗТОЧНИЦИ:` след всяка категория).

Файловете се генерират и се свалят от инструмента „Градски досиета“ (Claude artifact) — пействаш отговора
на Gemini там и бутонът "Изтегли .md" пуска файл с готовото име, който просто се пуска в тази папка.
